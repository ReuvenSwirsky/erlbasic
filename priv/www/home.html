FunctionTown Public Access

Classic Time Sharing, Modern Erlang Reliability

FunctionTown is a shared BASIC environment inspired by RSTS/E style computing. Your browser connects to an Erlang-powered timesharing service where multiple users can log in, edit, and run BASIC programs in isolated sessions.

Open BASIC Terminal

What is FunctionTown?

A hosted BASIC community where old-school workflows are first-class: numbered lines, immediate mode, program files, and shared machine culture.

What is RSTS/Erlang?

This system blends a RSTS-like user model with Erlang supervision and concurrency. Crashes are isolated, sessions can be managed independently, and system services stay online.

How to Start

Use the terminal link above to sign in. From there you can load programs, run examples, and interact with graphics and text applications in your own session.
