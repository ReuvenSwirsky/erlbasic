FunctionTown Public Access

Make your own homepage in BASIC

FunctionTown is a shared BASIC system where every account can publish a personal page by writing HOME.BAS. You log in, type a normal BASIC program, and the server turns its rendered text and graphics into a public page at /username.

Publish With HOME.BAS

Your homepage is just another program file. Create HOME.BAS, use PRINT, COLOR, LOCATE, or graphics statements, then call HOME PUBLISH to flush a panel onto the page.

Check it out!

Visit /thrillscience for a live BASIC-authored homepage running on this system. Then create an account and make your own!

How It Feels

This is old-school timesharing on purpose: numbered lines, immediate mode, saved program files, and public pages that come straight from your BASIC code -- text and graphics!

Quick Start

Open the terminal, sign in, type this starter program, then SAVE HOME.BAS. Your page appears at your account URL the next time it is loaded.

NEW 10 COLOR 14,1 20 PRINT "HELLO FROM FUNCTIONTOWN" 30 PRINT "THIS PAGE IS WRITTEN IN BASIC" 40 HOME PUBLISH 50 END SAVE HOME.BAS
1. Open /s/term and sign in.
2. Enter the program exactly as shown and save it as HOME.BAS.
3. Reload /yourname to see your published page.

Why Erlang

The system blends a RSTS-like user model with Erlang supervision and concurrency, so each session stays isolated and the service keeps running even when one program fails.
