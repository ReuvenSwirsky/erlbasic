# Your BASIC Homepage

Every user account has a personal homepage served at:

```
http://<server>/<username>
```

For example, if your username is `alice`, your page lives at `http://myserver/alice`.

The page is generated by a BASIC program called `HOME.BAS` that lives in your program directory. You write it exactly like any other BASIC program, but with a special directive — `HOME PUBLISH` — that controls what gets displayed on the page.

---

## How It Works

When someone visits your homepage URL, the server runs your `HOME.BAS` silently (no terminal output). You use ordinary BASIC statements — `PRINT`, `COLOR`, `LOCATE`, `CLS` — to build up a virtual 80×24 text screen. When you execute `HOME PUBLISH`, that screen is snapshotted and added as a coloured panel on your page. The screen then clears, ready for you to build the next panel.

You can call `HOME PUBLISH` as many times as you like. Each one adds another panel below the previous one.

---

## Your First Homepage

### Step 1 — Start a new program

At the BASIC prompt, clear any program in memory:

```
NEW
```

### Step 2 — Type your program

```basic
10 REM My homepage
20 COLOR 14, 1
30 LOCATE 1, 1
40 PRINT "Hello, world!"
50 COLOR 7, 0
60 PRINT "Welcome to my page."
70 HOME PUBLISH
80 END
```

### Step 3 — Save it as HOME.BAS

```
SAVE HOME.BAS
```

That's all. The file is now stored in your directory.

### Step 4 — View your homepage

Open a browser and go to:

```
http://<server>/<your-username>
```

Your page will render immediately.

---

## Editing Your Homepage

Load it back into memory, make changes, and save again:

```
LOAD HOME.BAS
```

Edit individual lines or add new ones, then:

```
SAVE HOME.BAS
```

The cached version is automatically discarded the next time the page is requested because the file's modification date has changed.

---

## HOME PUBLISH Reference

| Statement | Effect |
|---|---|
| `HOME PUBLISH` | Snapshot the current screen as a page panel, then clear the screen |

`HOME PUBLISH` is only meaningful inside `HOME.BAS`. In any other program it is silently ignored.

## Useful Statements

### PRINT

```basic
PRINT "Some text"
PRINT "Value is: "; X
PRINT                    ' blank line
```

A `PRINT` with no trailing `;` moves to the next line. Use `;` to keep printing on the same line.

### COLOR *fg*, *bg*

Sets the foreground and background colour using CGA colour indices (0–15).

```basic
COLOR 14, 1    ' yellow text on blue background
COLOR 7, 0     ' light grey on black (the default)
```

| Index | Colour       | Index | Colour          |
|-------|--------------|-------|-----------------|
| 0     | Black        | 8     | Dark grey       |
| 1     | Dark blue    | 9     | Bright blue     |
| 2     | Dark green   | 10    | Bright green    |
| 3     | Dark cyan    | 11    | Bright cyan     |
| 4     | Dark red     | 12    | Bright red      |
| 5     | Dark magenta | 13    | Bright magenta  |
| 6     | Brown        | 14    | Yellow          |
| 7     | Light grey   | 15    | White           |

### LOCATE *row*, *col*

Moves the cursor to row *row*, column *col* (both 1-based). The screen is 80 columns × 24 rows.

```basic
LOCATE 1, 1           ' top-left corner
LOCATE 12, 40         ' middle of the screen
```

### CLS

Clears the screen, homes the cursor, and resets colours to the defaults (light grey on black).

## Multiple Panels

Each `HOME PUBLISH` starts a fresh screen. This lets you divide your page into separate visual sections:

```basic
10 REM Panel 1 — banner
20 COLOR 10, 0
30 PRINT "=== MY HOMEPAGE ==="
40 HOME PUBLISH

50 REM Panel 2 — bio
60 COLOR 7, 0
70 PRINT "Name:    Alice Smith"
80 PRINT "Project: [1,5]"
90 HOME PUBLISH

100 END
```

---

## Tips

- **The screen is 80×24.** `LOCATE` coordinates outside that range are clamped to the boundary.
- **Trailing spaces are trimmed** from each row to keep the HTML compact.
- **The page is cached.** After a `SAVE HOME.BAS`, the cached copy is regenerated on the next page view. You do not need to restart the server.
- **`HOME PUBLISH` without any preceding output** produces an empty panel — just a blank black box. Put it after your `PRINT` statements.
- **`HOME` with any subcommand other than `PUBLISH`** is a syntax error in normal programs. It is parsed at startup and silently skipped in all non-homepage contexts.
